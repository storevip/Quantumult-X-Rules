Quantumult X AI 分流规则

这是一套适用于 Quantumult X 的通用 AI 分流规则，主要用于统一管理常见海外 AI 服务的网络访问，让不同订阅、不同机场、不同节点用户都可以方便使用。

目前规则主要覆盖：

ChatGPT / OpenAI
Claude
Gemini
Grok
Manus
Perplexity
Microsoft Copilot
Poe
Cursor
以及其他常见海外 AI 服务

规则将 AI 流量统一交给独立的 AI 策略组 管理，同时可搭配美国、日本、台湾、新加坡、韩国等地区节点使用。

在节点匹配方面，会尽量通过节点名称、国家名称、国旗、英文缩写等方式自动识别，因此不依赖某一家机场或固定订阅，更换订阅后也能继续使用。

主要特点
覆盖主流海外 AI 服务
AI 流量统一分流管理
支持多个常用地区节点
自动识别节点名称、国旗及常见缩写
不绑定特定机场或订阅
支持手动选择 AI 节点
更换订阅后无需大量修改配置
支持通过 GitHub 远程更新规则
后续可持续补充新的 AI 服务
适用场景

适合希望将 ChatGPT、Claude、Gemini、Grok、Manus 等 AI 服务统一管理的 Quantumult X 用户。

一套规则，统一管理常用 AI 服务；不挑机场，换订阅也能继续使用。
